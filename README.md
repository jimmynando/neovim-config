# Personal Nvim

## What is this?
Customized Nvim to give the user a IDE experience.

## Features
- Treesitter
- Nvimtree
- LSP
- ESLint
- Lua Line
- Telescope
- Alpha Dashboard

## Keymaps
`
Ctrl + n -> Nvimtree toggle
Ctrl + p -> Telescope
Ctrl + Shift + f -> Search in file
K -> Hover
gd -> Definition
gr -> References
<leader> + rn -> rename
Ctrl + Down -> Move cursor down
Ctrl + Up -> Move cursor up
Ctrl + Left -> Move cursor left
Ctrl + Right -> Move cursor right
<leader> + f -> Fotmat
` 
## Installation
Clone the repo inside the ~/.config dir

`
git clone https://github.com/jimmynando/neovim-config.git
